# Hi, I'm Ivy 👋

I'm a product designer who builds what I design — and lately, a lot of little apps of my own.

I spent 7+ years as a founding and lead designer at early-stage startups, where the line between the Figma file and the pull request got pretty blurry. These days I like working in that blur: sketching an idea, prototyping it in code, and shipping it.

## What I'm making

- **Birdpath** — a bird discovery app for iOS, built on eBird and BirdCast data. (SwiftUI, Supabase, PostGIS)
- **BirdLog** — a live migration map with a Pokédex-style collection mechanic. (Expo / React Native)
